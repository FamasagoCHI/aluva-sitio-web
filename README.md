# ALUVA - Sitio Web

Proyecto desarrollado para la asignatura Diseño Web de la carrera Ingeniería en Informática.

## Descripción

Sitio web desarrollado para ALUVA, emprendimiento orientado a ropa de trabajo, elementos de protección personal (EPP) y vestuario personalizado.

El proyecto presenta información de la empresa, productos, testimonios, datos de contacto y acceso al catálogo ALUVA 2026.

## Características

- Diseño web responsive.
- Navegación mediante menú principal.
- Slider de presentación.
- Sección Quiénes somos.
- Catálogo de productos.
- Testimonios.
- Información de contacto.
- Enlaces a redes sociales.
- Acceso al catálogo ALUVA 2026 en formato PDF.
- Adaptación para escritorio, tablet y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Revolution Slider

## Diseño responsive

El sitio fue probado en diferentes tamaños de pantalla para comprobar su correcta adaptación:

- Escritorio.
- Tablet (iPad Mini 768 × 1024).
- Dispositivo móvil (iPhone 16 Pro Max 440 × 956).

## Despliegue

El sitio se encuentra publicado mediante Netlify.

**Sitio web:** https://aluva-sitio-web.netlify.app

## Estructura principal

- `index.html`: página principal.
- `css/`: estilos del sitio.
- `js/`: archivos JavaScript.
- `imagenes-aluva/`: imágenes utilizadas por ALUVA.
- `images/`: recursos gráficos del template.
- `catalogo/`: catálogo ALUVA 2026.
- `bootstrap/`: recursos de Bootstrap.
- `revolution/`: recursos utilizados por Revolution Slider.
